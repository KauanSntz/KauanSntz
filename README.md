## Projetos em destaque

**[IdosoSeguro+ Manaus](https://github.com/KauanSntz/IdosoSeguro-Manaus)** — PWA que ensina idosos a reconhecer golpes digitais. Dois modos: conteúdo educativo com quiz e análise de mensagens suspeitas por motor heurístico em Python. Interface acessível (WCAG 2.2 AA), offline-first, API em Node/Express e SQLite. A análise é stateless: nada do que a pessoa envia é armazenado.

**[Painel Câmbio Local](https://github.com/KauanSntz/painel-cambio-local)** — dashboard de cotações que roda 100% na máquina. Servidor HTTP em Python puro, histórico em JSON, camada analítica em SQLite com controle de estoque por FIFO e exportação para planilha.

**[Portal de Inscrições](https://github.com/KauanSntz/portal-inscricoes)** — portal estático com central de links por unidade e modalidade e consulta de cursos e preços.
